# Make Knowledge Cards

## Overview

把用户提供的文章——粘贴的文本或本地 `.md` / `.txt` 文件——提炼成 5~8 张知识卡片，用于复习与记忆。三条底线：只保留真正重要的知识；一张卡片只讲一个知识点；绝不编造原文没有的信息。

## 适用范围

- **支持**：用户粘贴的文章、笔记等文本；本地 `.md`、`.txt` 文件（用文件读取工具读取内容）。
- **不支持**：网页抓取（URL）、PDF、Anki、图形界面。用户提出这类需求时，直接说明本 Skill 暂不支持，请对方粘贴文本或提供 `.md`/`.txt` 文件，不要尝试变通实现。

## 工作流

### 第 1 步：获取原文

- 用户已粘贴文本 → 直接使用。
- 用户给出本地路径 → 读取该 `.md` / `.txt` 文件。
- 用户给出 URL / PDF / 其他格式 → 说明暂不支持，请求可用形式的输入。
- 原文的有效信息不足以提炼出 5 张卡片 → 如实输出能提炼的数量（可以少于 5），并向用户说明原因；不要注水凑数。

### 第 2 步：提炼知识点

通读全文，先列出候选知识点清单，再逐条筛选：

- **只留真正重要的**：核心概念、因果机制、关键数据或结论、可操作的方法、对常见误区的澄清。跳过引言、背景铺垫、过渡句、题外话和纯修辞内容。
- **一卡一点**：一个候选点若包含多个子概念，拆开成多张卡片，或只保留最核心的部分。对比/选择类内容（如两种方案的区别与取舍）算一个知识点，可合并为一张卡片，统一到"如何选择"。
- **去重**：同一知识点在文中多处出现时，只保留一张卡片，取最完整的表述。
- **排序**：按原文顺序或"由基础到进阶"排列，让卡片能被依次阅读。

### 第 3 步：按模板生成卡片

使用以下 Markdown 模板：

```markdown
### 卡片 N｜具体、有信息量的标题

- **核心知识**：一句话说清这个知识点（建议 30 字以内）。
- **解释**：2~4 句简明解释，全部基于原文。
- **例子**：原文中的例子；若原文没有例子，改用 **自测**：一个能从原文中找到答案的问题。
```

细节要求：

- 标题要具体（"间隔重复为什么有效"优于"记忆方法"）。
- 卡片语言与原文一致，除非用户另行指定。
- 例子字段是硬约束：**只能使用原文中出现的例子**，绝不能为了让卡片更生动而虚构场景、人物或数据。原文没有例子时，一律改用自测问题，没有例外。
- 默认直接在对话中输出卡片；用户要求保存时，写入一个 `.md` 文件。

### 示例

原文片段："间隔重复的原理是：在遗忘临界点复习，记忆效果最好。艾宾浩斯实验发现，20 分钟后人们平均忘记约 42% 的学习内容。"

生成的卡片：

```markdown
### 卡片 1｜间隔重复为什么有效

- **核心知识**：在遗忘临界点复习，记忆效果最好。
- **解释**：艾宾浩斯实验发现，人们在学习后 20 分钟平均忘记约 42% 的内容。间隔重复正是踩在遗忘发生的时机安排复习，从而用更少的重复次数维持长期记忆。
- **自测**：根据艾宾浩斯的实验，学习后 20 分钟人们平均忘记多少内容？
```

### 第 4 步：输出前自检

- [ ] 数量在 5~8 张之间；若少于 5 张，已向用户说明信息不足的原因
- [ ] 每张卡片只讲一个知识点
- [ ] 卡片之间没有重复内容
- [ ] 每条内容都能在原文中找到依据——没有编造事实、数据或引文
- [ ] 例子的内容来自原文（原文没有例子时已改用自测）；自测问题的答案可以在原文中找到
