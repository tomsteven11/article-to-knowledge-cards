# make-knowledge-cards

一个把文章变成知识卡片的 Agent Skill。

## 解决什么问题

读完一篇文章，真正被记住的内容往往很少；而手动把文章整理成笔记或闪卡，又要花大量时间筛选、归纳、排版。本项目把这个整理工作交给 AI Agent 完成并提供质量约束：你只需给出一篇文章，Agent 按 Skill 中固定的提炼规则和卡片模板，产出可直接用于复习与记忆的结构化知识卡片，避免"想到哪写到哪"和 AI 常见的编造、注水问题。

## 主要功能

- 输入一篇文章，输出 5~8 张知识卡片，每张卡片包含四部分：
  - **标题**：具体、有信息量的知识点名称
  - **核心知识**：一句话说清这个知识点
  - **解释**：2~4 句简明解释，全部基于原文
  - **例子或自测**：原文中的例子；原文没有例子时，给一个能从原文中找到答案的自测问题
- 提炼规则（内置在 Skill 工作流中，Agent 必须遵守）：
  - 只提取真正重要的知识（核心概念、因果机制、关键数据或结论、可操作的方法、误区澄清）
  - 一张卡片只讲一个知识点
  - 重复内容自动合并去重
  - 不编造原文没有的信息，例子只能来自原文
  - 原文信息不足时不强行凑数（可以少于 5 张，但会说明原因）
- 卡片语言与原文一致，除非用户另行指定
- 默认直接在对话中输出；可按要求保存为一个 `.md` 文件

## 安装方法

本 Skill 遵循开放的 Agent Skills（SKILL.md）格式，适用于支持该格式的 AI 编码助手（如 Codex）。

```bash
# 将 Skill 文件夹复制到 Agent 的 Skill 目录，例如 Codex：
cp -r skills/make-knowledge-cards ~/.codex/skills/
```

其他产品按其 Skill 安装说明，把 `skills/make-knowledge-cards` 放入对应目录即可。

## 使用方法

安装后对 Agent 说（二选一）：

```text
用 make-knowledge-cards 把这篇文章整理成知识卡片：<粘贴文章正文>
```

```text
用 make-knowledge-cards 处理 ./notes/http-cache.md
```

支持的输入：直接粘贴的文本，或本地 `.md` / `.txt` 文件。

**暂不支持**：网页抓取（URL）、PDF、Anki 导出、图形界面——提出这类输入时，Agent 会按 Skill 约定说明不支持，并请求粘贴文本或 `.md`/`.txt` 文件。

## 输入 / 输出示例

输入（粘贴正文或 `.md` / `.txt` 文件）：

> 间隔重复的原理是：在遗忘临界点复习，记忆效果最好。艾宾浩斯实验发现，20 分钟后人们平均忘记约 42% 的学习内容。……

输出：

```markdown
### 卡片 1｜间隔重复为什么有效

- **核心知识**：在遗忘临界点复习，记忆效果最好。
- **解释**：艾宾浩斯实验发现，人们在学习后 20 分钟平均忘记约 42% 的内容。间隔重复正是踩在遗忘发生的时机安排复习，从而用更少的重复次数维持长期记忆。
- **自测**：根据艾宾浩斯的实验，学习后 20 分钟人们平均忘记多少内容？
```

实际测试过的输入类型：中文技术文章（`.md`，输出 7 张）、英文科普文章（`.txt`，输出 6 张、语言跟随英文原文）、信息量很少的通知类短文（输出 2 张并说明原因）。
